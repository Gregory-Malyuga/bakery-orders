# Search

Поиск пользователей в текущем приложении выполняет PostgreSQL через `UserRepository`. Общий фильтр `SearchFilter` ищет по имени, а `EmailFilter` применяет регистронезависимое сравнение к почте. Результат остаётся обычным Eloquent-запросом с пагинацией `BaseRepository`.

Elasticsearch не входит в текущий Compose, не вызывается при создании и изменении пользователей и не предлагается генератором `make:domain`. Оставшиеся классы Elasticsearch относятся к прежнему каркасу и не включены в рабочий путь приложения.

См. также: [Persistence](persistence.md).
