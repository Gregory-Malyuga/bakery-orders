# BAK-26 · локальные зависимости и структура приложения

## Постановка

PhpStorm должен читать Composer-пакеты из локальной папки `vendor/`. Переходный домен `app/Domains/Bakery/` нужно убрать: классы, принадлежащие одному сценарию, перенести в профильный домен; действительно общие — в `app/Shared/`. Blade-шаблоны сгруппировать по сценариям и уменьшить крупные шаблоны там, где это делает код понятнее. Вычисления, разбор сохранённых снимков и правила предметной области вынести из Blade в подготовку данных профильных доменов.

## Критерии приёмки

- Локальный Compose работает с `./vendor`, в том числе при первом запуске с пустой папкой, а PhpStorm видит исходники пакетов на хосте.
- В `app/Domains/Bakery/` не осталось классов и ссылок на их namespace. Переходные наследники заменены владельцами из профильных доменов; нужные только одному сценарию сервисы перенесены к нему. Исторические имена таблиц и публичные URL сохраняют совместимость.
- Blade-файлы сгруппированы по функциональным областям; все `view`, `@include` и `@extends` указывают на существующие файлы. Разбиение крупных шаблонов не меняет форму запросов и итоговый HTML.
- Blade не выполняет запросы к БД и не получает Eloquent-модели, способные запустить ленивую загрузку связей. Обработчики и контроллеры передают отдельные readonly value objects со всеми полями, нужными шаблону.
- В Blade нет расчётов сумм, количеств или правил состояния; шаблоны получают готовые значения и отвечают за отображение.
- На отдельной тестовой БД в Docker проходят `composer pre-commit` и полный `composer pre-push`; маршруты и ключевые страницы проверены локально.

## Текущее состояние

22.11.2026: `vendor` скопирован из текущего Docker-тома в игнорируемую Git локальную папку; Compose переключён на bind mount и дополнен установкой при пустой папке. Шаблоны маршрутных листов собраны в `resources/views/bakery/delivery/`. Домен `Bakery` затем удалён: ссылки переключены на профильные модели и сервисы, фабрика магазина перенесена к `Store`, регистрация переходного провайдера удалена. Полный локальный gate после удаления домена и подготовки данных печатного листа прошёл: 272 теста, 1805 утверждений. Остальная очистка Blade открыта.
