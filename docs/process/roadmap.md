### Открытая ошибка

- [x] **BUG-09 · P1** — [production `/admin` отвечает 500 после релиза с новой схемой возвратов](bugs/BUG-09.md). Воспроизведение: открыть `/admin` авторизованным администратором на `backery`; в журнале SQLSTATE 42703, миграция `2026_11_01_120000_add_bakery_return_cancellations` не запущена. Требуется автоматический запуск миграций при релизе и проверка `/admin` после него.
- [x] **BUG-08 · P1** — [web-сессии клиентов теряются после релиза](bugs/BUG-08.md). Воспроизведение со слов пользователя: войти, перезапустить Docker Compose при релизе, открыть `/orders` — требуется повторный вход. На `backery` подтверждены PostgreSQL-сессии и срок неактивности 120 минут; потеря активной сессии при перезапуске не воспроизведена. Подготовлены 30-дневный срок и регрессионный тест; нужны прогон тестов и проверка после релиза.

- [x] **BUG-07 · P1** — Pint в CI на `93cd359` сообщает 1 style issue в `app/Shared/Console/DomainGenerator/Contracts/AbstractGenerator.php` (`no_unu…`; 275 файлов, exit 1). Воспроизведение: `php vendor/bin/pint --test`. После удаления Elasticsearch-хелперов остался импорт `DomainContext`; импорт удалён. Требуется повторный Pint и полный CI.
- [x] **BUG-06 · P1** — PHPStan в CI на `0655758` завершается кодом 1 с двумя `trait.unused`: `InteractsWithElasticsearch.php:13` и `RefreshElasticsearch.php:8`. Воспроизведение: `php vendor/bin/phpstan analyse --memory-limit=512M` после удаления Elasticsearch из рабочего стека. Удалены неиспользуемые трейты и флаг генератора `--with-elasticsearch`; требуется повторный PHPStan и полный CI.
- [x] **BUG-05 · P1** — ParaTest в CI: `UserStatusGateTest::test_flag_off_pending_user_passes` иногда получает 403 вместо 200. Воспроизведение: `php vendor/bin/paratest --processes=2 --runner=WrapperRunner --log-junit=report.xml` на `6d79477` (192 теста, 1 сбой). Фабрика случайно назначает роль `user`, которую отдельно запрещает `bakery.role:legacy-api`. Во всех сценариях теста задана роль `manager`; требуется повторный прогон CI, включая этот тест и полный набор.
- [x] **BUG-01 · P1** — CI останавливается на Deptrac: `AdminWebController` зависит от инфраструктурного `PeriodReportWorkbook`. Воспроизведение: `php vendor/bin/deptrac analyse --config-file=deptrac.yaml --fail-on-uncovered` на `670aea7` завершается кодом 1 с нарушением `PresentationLayer on InfrastructureLayer`. Ожидается успешная архитектурная проверка и работа выгрузки отчёта. Исправление подготовлено в отдельном worktree, ожидает проверки CI.
- [x] **BUG-03 · P1** — PHPStan в GitHub Actions завершает `analyze-phpstan` с ошибками (`php vendor/bin/phpstan analyse --memory-limit=512M`). На `670aea7` было 105 ошибок, после `ee9eedb` осталось 2: `ProductionCalculator.php:154` и `RecipeWebController.php:41`. Ожидается exit 0, фактически exit 1. Уточнены вычисление типа теста и форма записи ингредиента; требуется повторный PHPStan и полный CI.
- [x] **BAK-01 · P0** — [отменить ошибочный возврат без потери истории](../backlog-2026-11-01.md#bak-01--отмена-ошибочного-возврата--p0). Сообщение пользователя: один возврат случайно записан дважды, удалить его нельзя.
- [x] **BUG-02 · P1** — [SARIF upload падает в CI](bugs/BUG-02.md). После добавления `actions: read` GitHub сообщает `Code scanning is not enabled for this repository`; отчёты Trivy переведены в артефакты workflow, ожидается проверка в CI.
- [x] **BUG-04 · P1** — Pint на `5d74858` завершил `lint-code-style` с 3 ошибками; после коммита `37126e2` остаётся один файл: `IngredientCatalog.php` (`phpdoc_separation` и правило PHPDoc, название которого обрезано в журнале). Воспроизведение: `php vendor/bin/pint --test` в CI. Ожидается exit 0; исправлен пробел после `@param` и разделены группы аннотаций, повторная проверка CI ещё нужна.
