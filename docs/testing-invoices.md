# Регрессионное тестирование накладных и печати

Новые тесты `InvoicePrintRegressionTest` создают заказ на три изделия по 12,34 ₽, формируют печатный HTML и реальный XLSX, затем проверяют заголовки колонок и денежные значения.

| Сценарий | HTML/печать | XLSX |
| --- | --- | --- |
| Возвратов нет | Нет возвратных колонок; итог 37,02 ₽ | Пять колонок, сумма 37.02 |
| Активный возврат одного изделия | Колонки возврата появляются; итог 24,68 ₽ | Семь колонок, итог 24.68 |
| Возврат отменён | Колонки отсутствуют; итог 37,02 ₽ | Без колонок возврата |
| Дополнительный возврат | Отражён в сумме к оплате | Включён в расчёт итогов |
| Документ для печати | Название, адрес, товар, кнопка печати, ссылка XLSX | — |

## Обязательные последующие проверки

- `FinancialConsistencyTest`: согласованность финансовых значений, истории, отчётов.
- `GroupInvoiceRegressionTest`: обычные группы, Балтийская и Колпино, возвраты и их отмена.
- `GroupWorkbookLayoutTest`: оформление нижней таблицы Excel.
- Проверка реальной печати в браузере и открытия XLSX в Excel необходима дополнительно к программным тестам.

Команды: `php artisan test --filter=InvoicePrintRegressionTest`, `php vendor/bin/phpstan analyse --memory-limit=512M`, `php vendor/bin/pint --test`.

**Статус:** код тестов добавлен в ветку; локальные PHP, CI, браузерная печать и Excel в этой среде не проверены. Ни один результат нельзя считать подтверждённым до CI.

## Дополнительные тесты — формулы и структура XLSX

- Проверка точных адресов ячеек и формул суммирования для накладной без возвратов (`D7`, `E7`, `E8`) и с возвратом (`D7`, `F7`, `G7`, `F8`, `G8`).
- XML-проверка основных частей ZIP-пакета XLSX: workbook, листы, стили, связи, content types. Подтверждается наличие итогового листа и принудительного пересчёта формул.
- Проверка настроек страницы для печати: ориентация, масштабирование по ширине.
- Печатный HTML экранирует пользовательский комментарий и сохраняет цену из заказа после изменения текущего прайса.
- Выгрузка пустой даты содержит понятную заглушку и лист сводного заказа.

Проверка ZIP/XML не заменяет интеграционного открытия файла в Microsoft Excel и проверки физической печати. Новые проверки должны пройти PHPStan, Pint и ParaTest в CI.
