# Troubleshoot

1. Зафиксировать симптом, среду и способ воспроизведения. Найти возможный паттерн в `docs/history/checklist.md`, затем проверить его на текущем коде.
2. Повторить проблему на безопасных данных. Для денег сопоставить заказ, действующие возвраты, административную страницу, печать и XLSX; для тестов начать с конкретного теста и отдельной тестовой БД.
3. Отделить факты от гипотез, установить причину и проверить исправление на видимом результате.
4. Открытый дефект записать как `BUG-XX` в текущем `docs/process/roadmap.md` по `docs/process/bug-template.md`. Для разобранного и исправленного сбоя добавить `HIST-NNN.md` и строку в `docs/history/checklist.md` через `/history`.

Полный процесс: `docs/process/work-items.md`. Не обозначать недоступные проверки как пройденные.
