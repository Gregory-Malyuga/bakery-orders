# /wrap-up

Закрыть задачу после выполнения критериев приёмки по [процессу](../../docs/process/work-items.md). Непрошедшие или недоступные проверки указать явно.

## Шаги

1. Сверить результат с критериями задачи, отметить `[x]` только в текущей очереди `docs/process/roadmap.md`.
2. Обновить `docs/state.md`:
   - **Now / Next / Blocked** → фактическое состояние;
   - **Verification** → что действительно проверено, что нет;
   - дата и локальный commit SHA, если коммит создан.
3. Если найден новый дефект продукта, оставить его открытым как `BUG-XX` в roadmap. Для установленной причины и исправления неожиданного сбоя добавить `HIST-NNN` через `/history`.
4. В итоговом отчёте отдельно указать локальный коммит, push, CI и production-деплой.

Коммитить только согласованный объём. Обновление roadmap и state входит в коммит задачи, если локальный коммит запрошен; push и деплой требуют отдельной авторизации.
