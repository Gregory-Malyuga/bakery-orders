# /implement

Взять следующую незакрытую задачу из **текущей очереди** `docs/process/roadmap.md` и реализовать её по [процессу](../../docs/process/work-items.md). Архивные пункты roadmap не выбирать автоматически.

## Шаги

1. Прочитать `docs/state.md` и проверить, относится ли Blocked к этой задаче.
2. Прочитать текущую очередь `docs/process/roadmap.md`, затем подробную постановку выбранного ID. Проверить `git status` и сохранить несвязанные изменения.
3. Обновить `docs/state.md` → Now: `<ID и название>` · Next: `<следующая>`.
4. Если задача — новый класс/компонент: создать скелет через `artisan make:*` (если уместно)
5. Реализовать по порядку из `docs/process/tdd.md`
6. Проверить видимое поведение на затронутых страницах, в печати и Excel; после релевантных тестов выполнить `/pre-push`, если окружение доступно. Зафиксировать фактические результаты.
7. При выполнении критериев приёмки: `/wrap-up`. Не закрывать задачу только по факту изменения кода.
